# Docker setup steps (Sara Worldwide Chatbot)

- [ ] Create Docker Desktop engine running (WSL2 engine)
- [ ] Run: `docker compose build`
- [ ] Run: `docker compose up -d`
- [ ] Check logs: `docker compose logs -f backend`
- [ ] Confirm DB is seeded (backend startup runs `python setup_db.py`)
- [ ] Open app: http://localhost:8000/
- [ ] Test API: http://localhost:8000/api (or /api/products depending on routes)
